# 🚀 GitHub 仓库桌面管理器 (GitHub Repo Desktop Manager)

一款轻量、极速且安全的高颜值 GitHub 仓库桌面管理仪表板。基于 GitHub CLI (`gh`) 官方鉴权体系构建，无需在任何地方填写或硬编码个人私钥 Token，纯本地运行，即开即用。

---

## ✨ 核心特性

- **⚡ 秒级极速启动**：Windows 双击 `.bat`（或桌面快捷方式）即开，macOS/Linux 单命令启动，自动唤起默认浏览器。
- **➕ 一键极速创建**：支持设置仓库名称、描述、公开/私有属性、自动初始化 README、选择 `.gitignore` 模板与开源许可证。
- **🗑️ 安全防误删机制**：集成二次防误触确认机制（必须手动输入仓库名确认），调用底层 API 彻底清理无用远程仓库。
- **⏱️ 活跃度与健康洞察**：
  - **创建时间**：直观展示仓库成立日期与已存在时长（如 `2024-05-31 (5个月前)`）。
  - **维护频率**：根据最后一次 Push 提交时间智能评级（🟢 近期活跃 / 🟡 常规维护 / ⚪ 较久未更新）。
  - **核心技术**：主编程语言色标、仓库体积 (KB/MB)、星标 Stars 与 Fork 数。
- **📖 抽屉式代码概览**：无需反复打开 GitHub 网页，点击即可直接阅读**完整渲染后的 README.md**、**根目录文件结构树** 与 **最近提交记录**。
- **🛡️ 纯本地零 Token 泄露**：不存储任何明文密钥，所有请求仅在 `127.0.0.1` 本机环回地址通信，安全无忧。
- **🔌 智能端口避让**：默认端口 `3366` 若被占用，自动智能顺延（3367, 3368...），绝不闪退。

## 🏁 快速上手 (30秒运行)

### 前置条件
本工具依赖您本机安装的两个基础开发者环境：
1. **Node.js**（版本 ≥ 18）: [前往官网下载](https://nodejs.org/)
2. **GitHub CLI (`gh`)**: GitHub 官方命令行工具

> **未安装 GitHub CLI？复制以下命令一键安装：**
> - **Windows** (PowerShell / CMD): `winget install --id GitHub.cli`
> - **macOS** (Terminal): `brew install gh`
> - **Linux** (Ubuntu/Debian): `sudo apt install gh`

安装后只需在终端执行一次登录（根据屏幕提示在浏览器完成授权即可）：
```bash
gh auth login
```

---

### 启动运行

#### 🪟 Windows 用户：
- **方式一（直接启动）**：双击运行本目录下的 `启动GitHub管理器.bat`。
- **方式二（桌面快捷方式）**：双击运行 `创建桌面快捷方式.bat`，即可在 Windows 桌面上生成专属运行图标，以后直接在桌面上双击图标即可！

#### 🍎 macOS / 🐧 Linux 用户：
在终端执行以下命令：
```bash
chmod +x start.sh
./start.sh
```

启动完成后，系统将自动在您的默认浏览器中打开管理面板（默认地址：`http://127.0.0.1:3366`）。

## ⚠️ 关键注意事项与使用须知

### 1. 关于「删除仓库」的权限授权说明
> [!IMPORTANT]
> 出于账户安全保护，GitHub CLI 在初始登录时**默认不开启** `delete_repo`（删除仓库）高危权限。
> 
> 如果您希望在工具中使用**删除仓库**功能，请在您的电脑终端中执行一次以下命令开启授权：
> ```bash
> gh auth refresh -s delete_repo
> ```
> 终端会弹出浏览器确认窗口，点击确认即可。若未开启此权限，您仍可正常使用浏览、创建、README 预览等所有其它功能。

### 2. 共享与分发给其他人使用时的注意点
- **零隐私泄露**：您可以将此项目文件夹直接打包发送给任何朋友或同事。项目代码内没有任何您的私密凭据。
- 对方解压运行后，工具将自动调取**他自己电脑上的 GitHub 登录凭据**，展示并管理他自己的仓库，绝不会访问到您的账号。
- **打包建议**：分发给他人前，可以删除体积庞大的 `node_modules` 文件夹。启动脚本在检测到没有依赖时，会自动执行轻量安装。

### 3. 网络与代理设置 (针对国内用户)
如果在使用过程中遇到 GitHub API 响应超时或获取失败，通常是因为网络连接 GitHub 异常：
- 请确保您的系统代理/科学上网工具处于正常开启状态。
- 如需为 GitHub CLI 单独设置代理，可在终端运行：
  ```bash
  # 例如本地 Socks5 代理端口为 7890
  gh config set http_unix_socket ""
  # 或在环境变量中设置 HTTP_PROXY / HTTPS_PROXY
  ```

## 📂 项目结构概览

```text
├── 启动GitHub管理器.bat   # Windows 一键启动脚本 (带环境检测)
├── 创建桌面快捷方式.bat   # Windows 桌面快捷方式生成脚本
├── start.sh              # macOS / Linux 启动脚本
├── server.js             # 本地 Express 后端，直通 GitHub CLI
├── dist/                 # 前端打包后的生产环境静态资源 (秒开核心)
├── src/                  # React 18 前端源码
│   ├── App.jsx           # 主仪表板、模态框、抽屉与状态逻辑
│   ├── index.css         # 暗黑极客质感 Glassmorphism 样式体系
│   └── main.jsx          # 前端应用入口
├── vite.config.js        # Vite 构建配置文件
├── package.json          # 项目依赖配置
└── README.md             # 本说明文档
```
